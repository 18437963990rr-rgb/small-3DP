# 层间铺粉与清洗并行 — 试改说明（2026-06-04）

## 启用方式

| 环境变量 | 值 | 作用 |
|----------|-----|------|
| `METEOR_LAYER_INTERLEAVE_POWDER_CLEAN` | `1` | 层末 **铺粉(Command2)** 与 **下一层 Pass0 前清洗(Command1)** 并行 |
| `METEOR_CLEAN_WIPE_BACK_SPEED_MM_S` | 如 `80` | 清洗短流程 855→750 回刮速度（默认 20 mm/s） |

未设置 `METEOR_LAYER_INTERLEAVE_POWDER_CLEAN=1` 时行为与改前一致（仅新增 `[LayerAnchor]` 日志与可选回刮提速）。

## 改动文件

- `PrintLayerTransitionAnchors.cs` — 层间锚点状态
- `主界面.cs` — Pass0 清洗跳过、层末 `RunLayerEndPowderAndDeferredClean`
- `手动操作界面.cs` — Pass0 开扫前等待清洗锚点、清洗回刮速度、锚点置位
- `3-GoogolMotionMap.cs` — 墨车/铺粉子系统互斥锁

## 时序（启用并行后，稳态）

```text
层 N 喷墨结束
  ├─ Task A: 铺粉层 N（轴 7/8/6/3，PowderTrainMotionGate）
  └─ Task B: 清洗层 N+1（轴 1/2/4，InkCarMotionGate）
  WaitAll → 进入层 N+1 Pass0
层 N+1 Pass0:
  - 若 A_CLEAN_DONE(N+1)：跳过 Pass0 前 Command1
  - Preheat / STARTJOB / SwathReady（与 750 解耦，仍在 525 进近后）
  - WaitCleanBeforePass0Scan → 开扫 X
```

首层仍在 Pass0 前同步清洗（无「上一层铺粉」可叠）。

## 日志验收

搜索 `[LayerAnchor]`：

- `LayerTransitionBegin` / `LayerTransitionEnd` + `elapsedMs`
- `SkipPass0InlineClean` — 层间清洗已在层末完成
- `A_POWDER_DONE` / `A_CLEAN_DONE`

## 回退

去掉环境变量或设为非 `1` 即可回到串行逻辑。
