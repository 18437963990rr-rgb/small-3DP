# 铺粉车行程、回程停靠与成型缸时序排查记录（2026-06-03）

## 1. 背景与目标

现场在**手动自动进给铺粉**（`NewAutoSupplyPowderThread2`）中出现：

- 粉车未到去程终点 **1017mm** 即停住（约 **907mm**）；
- 回零后显示 **112mm**，铺粉一层结束后变为 **107.8mm**；
- 监测窗口观感：去程终点处成型缸（轴8）未先下降，**回程启动后**才看到 Z 向动作。

本次目标：

- 厘清铺粉主链路、轴分工与停靠坐标语义；
- 恢复落粉站接粉（轴3）且与去程撒粉隔离；
- 修正回程停靠与返程前成型缸时序；
- 形成可复用的排查记录，便于后续改机或改参。

## 3. 问题一：未到 1017mm 停在约 907mm

### 3.1 现象（日志摘要）

```
PowderCarEntryDiag: axis7Mm=0.000, cfgHome=112, travel=1017
开启铺粉车…至 1017mm
（无「粉辊去程结束」）
手动停止后 axis7Mm≈907
```

### 3.2 原因分析

**（1）坐标基准丢失（典型）**

- `PowderCarHomeFlag=True` 但 `axis7Mm=0`，与 `cfgHome=112` 不一致；
- 软件仍按绝对坐标命令 **445 → 1017**，物理有效行程约 **1017−112≈905mm**，限位处数显约 **907mm**。

**（2）软件行程与机械行程**

- 20260202 备份中 `POWDERCAR_TRAVEL_DIST = 900`，当前为 **1017**；
- 若机械极限仍按 ~900mm 标定，命令 1017 会顶正限位。

**（3）监控循环与终点**

- 超声/IR 监控循环：`while (PosValue <= POWDERCAR_DROP_END)` → **925mm** 即退出；
- 随后 `while` 等待 `|Pos| >= 1017` 才进入返程前轴8下降；
- 若在 907 限位停住，第一个循环不退出（907≤925），线程空转，直至人工停止。

### 3.3 处理建议（运维）

1. 每次铺粉前执行**粉车回零**，确认 `axis7Mm ≈ ±112`，勿仅依赖 `PowderCarHomeFlag`；
2. 手动 Jog 轴7 记录正限位数显，确认能否到 1017；
3. 确认运行目录下 `AutoPrint-Configuration.json` 与编译版本一致。


## 4. 问题二：112mm 回零后变成 107.8mm

### 4.1 现象

- 回零 / 同步 OK：**112mm**；
- 铺粉回程日志：`铺粉车返回至站1：…107.8mm`；
- 下一层启动：`axis7Mm=107.800`。

### 4.2 原因（非漂移，系旧逻辑）

```csharp
// 旧代码
AimPos = m_dPowderCarHomeposition - m_dPowderStationCorrection;
// 112 - 4.2 = 107.8
```

现场确认：**112mm 与落粉孔对齐**；`m_dPowderStationCorrection`（如 4.2mm）为旧版「Home 再减微调」残留，同一坐标系下不应再减。

### 4.3 已修改（2026-06-03）

**文件**：`1-3DP主控界面(人机交互模块)/手动操作界面.cs`、`主界面.cs`

| 项 | 修改 |
|----|------|
| 回程 `AimPos` | 改为 `m_dPowderCarHomeposition`（112mm），不再减 correction |
| `NewAutoSupplyPowderThread2CureFirst` 就近回程 | `aimPosPosHome = cfgHome`，`aimPosNegHome = -cfgHome` |
| `IsPowderCarAtStationForFeed` | 站1 判定为 **±cfgHome** |
| `IsPowderCarCoordinateReadyForAuto` / 主界面同步 | `expectedStation = cfgHome` |

> `m_dPowderStationCorrection` 配置项仍保留于 JSON/界面，**自动铺粉回程与站1判定已不再使用**。


## 5. 成型缸（轴8）时序说明

### 5.1 一层铺粉 Z 轴顺序（`NewAutoSupplyPowderThread2`）

| 阶段 | 铺粉车 | 成型缸 |
|------|--------|--------|
| 铺粉前 | 站1 | 下降（层厚+1.5mm）→ 上升 1.5mm（可与站1接粉并行，见下节） |
| 去程 | → 预铺位 ~445 → 1017 | **不动** |
| 到终点 | 等 ≥1017（或限位） | 下降 1.5mm（防回程压粉） |
| 回程 | → Home 112 | 当车 ≤ 预铺触发位（~445）时上升 1.5mm |

层结束净高度：约 **本层开始 Z − 一层厚**；1.5mm 下/上为回程让位，成对抵消。

### 5.2 监测窗口「返程才下降」的原因

返程前代码为：

```csharp
TrapMoveUp(8, ..., TrapSpace=-1.5mm, ..., waitStop: false);  // 不等停
BackToStation2(...);  // 立即回程
// 原 Thread.Sleep(1000) 已注释
```

轴8 下降约 0.75s（1.5mm @ 2mm/s）与铺粉车回程并行，观感像「一返程才下降」。

### 5.3 已修改：去程终点等停

**常量**：`PowderCarTravelEndDwellMs = 600`（0.5~0.7s 取中值）

**顺序**（回程前）：

1. `TrapMoveUp(8, …, waitStop: false)` 发下降；
2. `WaitAxis8StableAfterTrap(...)` 等轴8停稳；
3. `Thread.Sleep(PowderCarTravelEndDwellMs)`；
4. `BackToStation2` 启动回程。

`NewAutoSupplyPowderThread2` 与 `NewAutoSupplyPowderThread2CureFirst` 均已套用。


## 6. 落粉站接粉（轴3）与去程撒粉隔离

### 6.1 设计要点

| 动作 | 轴 | 条件 |
|------|-----|------|
| 站1接粉 | 轴3 | 粉车在落粉站、`m_nEnablePowderStationFeed==1`、圈数 `m_dPowderSupplyRotateNum` |
| 去程撒粉 | 轴3 | 默认关：`m_nEnableTravelDispenseAxis3==0`，去程为超声 |

### 6.2 并行 prep（缩短节拍）

`RunPowderPrepParallel_ZDownAndStationFeed`：

- 轴8 下降（层厚+1.5mm，`waitStop=false`）与轴3 接粉并行；
- 发车前双轴等完成。

**配置**（`AutoPrintParamInTest` / `AutoPrint-Configuration.json`）：

```json
"m_nEnablePowderStationFeed": 1,
"m_nEnableTravelDispenseAxis3": 0
```
